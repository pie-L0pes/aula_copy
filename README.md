# Sistema de Agendamento

## Sobre a atividade

Nesta atividade foi desenvolvido um **Sistema de Agendamento**, contendo um CRUD básico para cadastrar, listar, editar e excluir agendamentos.

O sistema possui uma regra de negócio que **não permite realizar dois agendamentos no mesmo dia e horário**.

## Atividade

A atividade consiste em implementar uma nova regra de negócio no sistema:

**Não permitir agendamentos em datas que já passaram.**

O sistema deverá verificar a data escolhida no momento do cadastro. Caso o usuário tente realizar um agendamento para uma data anterior à data atual, o sistema deverá impedir o cadastro e informar o motivo.
